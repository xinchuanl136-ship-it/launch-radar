How the implied value is built

implied = TVL × 0.30 × (1 + clamp(7d change, −40%, +100%)) × (0.70 + 0.30 × min(age, 730 days) / 730)

TVL × 0.30

TVL is the value a protocol already secures, so it anchors the size of any token. A token worth thirty cents per dollar of TVL is the base claim; the other two pieces move it up or down.

Momentum

The seven-day TVL change is the freshest momentum the snapshot carries. It is clamped at −40% to +100% so one wild week cannot halve or double a protocol. A protocol with no reported change scores as flat.

Tenure

How long the protocol has run with no token yet. A long clean record is the best evidence the snapshot gives that the protocol is real: tenure runs from 0.70 for a brand-new protocol to 1.00 after two years. Unknown age counts as 180 days.

What it is not

It does not predict whether or when a token is issued, and it is the entry's own claim, never the snapshot's. A protocol that records no token may still have one its record does not carry — the board says “records no token”, never “has none”.
